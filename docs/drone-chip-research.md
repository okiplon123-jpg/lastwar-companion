## System Overview

- **Unlock:** Chip Lab (HQ 15, server day 82). All crafting unlocked at Lab level 20.
- **Activation:** Drone Center → Combat Boost Level 10 (server day 85).
- **Preset slots unlock at:** Combat Boost 10 / 150 / 300 / 400+
- **UR equip requirement:** 2 copies needed to place in slot ("Wstąpienie wymaga: 0/2")
- **UR chips CANNOT be used as Combat Boost material** — only SSR can
- **Resonance Set Bonus:** All 4 chips in a set at the same star level give a global squad multiplier

## Chip Slot 1: INICIAL MOVE (Inicjujący / Initial Move)

**Trigger:** Beginning of battle — absorbs opening burst damage

| Rarity | Name (EN) | Name (PL) | Effect |
|--------|-----------|-----------|--------|

## Chip Slot 2: ATTACK (Atak / Attack)

**Trigger:** Each time the drone bombs

| Rarity | Name (EN) | Name (PL) | Effect |
|--------|-----------|-----------|--------|
| **UR** | Lethal Firestorm | Śmiercionośna burza ognia | Drone targets +3. After bomb: matching-type heroes gain Attack = 9% Drone Attack for 4.5 sec |

- **2★:** Drone hits 1 extra target

## Upgrade Priority Order (2026 meta)

### Crafting order:
1. **Interference** (Memory Ultra Fission) — craft first
2. **Defense** (Gravitational Resonance Armor)
3. **Initial Move** (Absolute Quantum Field)
4. **Attack** (Lethal Firestorm) — craft last

### Star upgrade order:
1. All chips → **2★** (unlock milestone bonuses)
2. All chips → **5★** (major milestone for Attack chip)
3. **Initial Move → 8★** (damage reduction 12%→16%)
4. **Defense + Interference → 8★**
5. **Attack → 8★** (last)

## Vehicle Type Matching

Each chip is crafted for a specific vehicle type. Percentage bonuses apply to **matching-type heroes only**.
- Wrong type: loses type-specific amplification + breaks Resonance Set Bonus
- UR chips: stronger off-type benefit than SSR, but still loses Resonance bonus

### Recommended chip focus by vehicle:
- **Tank:** Initial Move + Defense combo (shields + sustained defense)
- **Aircraft:** Attack + Interference combo (bombing synergy)
- **Missile:** Attack + Interference combo (damage output)
